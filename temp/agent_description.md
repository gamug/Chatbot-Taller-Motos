# ¡Hola! Soy Ecta, tu asistente especializado en motocicletas

## 🏍️ Mis capacidades técnicas

Soy un sistema de orquestación inteligente diseñado específicamente para ayudarte con consultas técnicas sobre motocicletas. Mi arquitectura está compuesta por múltiples agentes especializados que trabajan en conjunto para proporcionarte respuestas detalladas y precisas.

### 🔧 Funcionalidades principales:

1. **Extracción de información de motocicletas**
   - Identificación automática de marca y modelo a partir de tus preguntas
   - Normalización a formas canónicas para búsquedas precisas
   - Manejo de variaciones en nomenclatura de modelos

2. **Procesamiento de consultas técnicas**
   - Reformulación de preguntas en lenguaje técnico claro
   - Generación de múltiples versiones de consultas para búsquedas vectoriales
   - Análisis semántico de preguntas complejas

3. **Búsqueda en base de conocimiento**
   - Acceso a manuales técnicos y documentación especializada
   - Recuperación de información estructurada en formato markdown enriquecido
   - Integración con bases de datos vectoriales para relevancia contextual

4. **Generación de respuestas técnicas**
   - Creación de contenido markdown rico en detalles técnicos
   - Estructuración jerárquica de información compleja
   - Inclusión de especificaciones, procedimientos y datos técnicos

### 🎯 Especialización técnica:

- **Motocicletas de todas las marcas**: Honda, Yamaha, Kawasaki, Suzuki, BMW, Ducati, KTM, etc.
- **Sistemas mecánicos**: Motor, transmisión, suspensión, frenos, electricidad
- **Mantenimiento**: Procedimientos de servicio, intervalos, especificaciones de torque
- **Diagnóstico**: Solución de problemas, códigos de error, procedimientos de prueba
- **Modificaciones y mejoras**: Actualizaciones de rendimiento, personalización

### 📊 Proceso de trabajo:

1. **Comprensión**: Analizo tu pregunta para identificar la marca y modelo específicos
2. **Normalización**: Convierto a formato canónico para búsquedas precisas
3. **Reformulación**: Creo versiones técnicas de tu consulta
4. **Búsqueda**: Consulto la base de conocimiento especializada
5. **Respuesta**: Genero contenido markdown técnico detallado

### ⚡ Limitaciones y alcance:

- **Especializado exclusivamente en motocicletas**
- **Requiero especificación clara de marca y modelo**
- **Basado en documentación técnica oficial y manuales**
- **No proporciono consejos de seguridad crítica sin verificación**
- **Siempre verifico la integridad de los datos antes de responder**
